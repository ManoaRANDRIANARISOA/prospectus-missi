1. Contexte du Dépôt awesome-free-llm-apis

Le dépôt GitHub mnfst/awesome-free-llm-apis (créé et maintenu par Manifest) est une référence mondiale recensant les fournisseurs d'IA qui mettent à disposition des tiers gratuits permanents (Permanent Free Tiers) pour l'inférence de modèles de langage.

0 € Garanti

Aucune carte bancaire requise

Tous les services référencés ne demandent aucun moyen de paiement pour activer l'inférence.

Standard OpenAI

Compatibilité universelle

Tous les endpoints utilisent la spécification standard OpenAI (/v1/chat/completions).

Agent Skill Prêt

Dossier free-llm-apis/SKILL.md

Le dépôt fournit des instructions pour être directement exploité par les agents de code IA.

2. Clarification : "Vieux modèles" ou Nouvelle Génération ?

💡
Pourquoi l'impression de "vieux modèles" est trompeuse :
Quand on pense aux API gratuites, on imagine souvent de vieux modèles 7B dépassés (comme Llama 2 ou d'anciennes variantes). Or, le catalogue du repo est extrêmement récent (mis à jour en octobre 2026). Il intègre la toute dernière génération de modèles ouverts majeurs.

Cependant, il faut bien distinguer deux catégories de modèles sur le marché mondial :

✅ Ce qui EST disponible gratuitement

Modèles Open-Weights & Free Tiers Subventionnés

  • GPT-OSS 120B & 20B (Modèles ouverts très performants)
  • DeepSeek-V4 (Flash & Pro, avec 400K à 1M de contexte)
  • Qwen 3.5 & 3.8 (jusqu'à 397B paramètres)
  • Google Gemini 3.8 / 3.7 Flash & 2.5 Pro (1M tokens)
  • Llama 4 Scout & Gemma 4 (31B)
  • Poolside Laguna 2.1 & Cohere North Mini (spécialisés Code)
❌ Ce qui n'est JAMAIS gratuit en API

Modèles propriétaires sous licence fermée

  • Claude 3.7 / 3.5 Sonnet (Anthropic ne propose AUCUN free tier API)
  • OpenAI o1 / o3-mini / GPT-4.5 (OpenAI facture au token sans free tier)
  • Raison : Le coût unitaire de calcul par requête est trop lourd pour être offert sans modèle publicitaire ou quota commercial payant.

4. Pourquoi OpenCode et Pas Claude Code ?

Vous avez mentionné que vous disposez déjà d'OpenCode sur votre PC, et vous vous demandiez ce qu'il fallait penser de Claude Code. Voici une comparaison objective :

OpenCode Desktop
Option Gagnante pour ce Repo

Installé sur votre PC : C:\Users\MANOA PC\AppData\Local\Programs\@opencode-aidesktop\OpenCode.exe

  • Compatible avec toutes les API gratuites : Supporte nativement les URL personnalisées (Groq, OpenRouter, Google, OVHcloud).
  • Coût d'exploitation : 0,00 € permanent.
  • Interface ergonomique : Interface graphique avec arbre de fichiers, système de diff en direct, application de patchs en 1 clic.
  • Multi-modèles à la volée : Permet de basculer entre Groq (rapide) et Gemini (grand contexte) selon le besoin.
Claude Code (CLI)
Incompatible avec le Gratuit

Outil terminal officiel d'Anthropic (@anthropic-ai/claude-code).

  • Verrouillé sur l'écosystème Anthropic : Conçu pour consommer l'API payante de Claude 3.7 Sonnet.
  • Coût : Payant au token (consomme rapidement des crédits lors d'analyses de répertoires entiers).
  • Incompatible avec ce repo : Ne permet pas d'indiquer simplement une clé Groq ou OpenRouter sans proxy complexe.
  • Verdict : Excellent si vous avez un compte payant Anthropic, mais inadapté si votre objectif est le zéro coût.

5. Guide Pas-à-Pas : Configuration d'OpenCode

1
Créer votre première clé gratuite (Exemple : Groq)

Groq est la recommandation n°1 pour la vitesse de génération et son modèle GPT-OSS 120B.

  1. Rendez-vous sur console.groq.com/keys.
  2. Créez un compte avec votre email ou votre compte GitHub (aucune carte bancaire demandée).
  3. Cliquez sur "Create API Key", donnez-lui un nom (ex: opencode-groq) et copiez la clé générée (commence par gsk_...).
2
Ouvrir OpenCode et accéder aux réglages

Lancez OpenCode sur votre machine. Cliquez sur l'icône d'engrenage Settings (ou raccourci Ctrl + ,) en bas à gauche de la fenêtre.

ℹ️
Si vous préférez modifier directement le fichier de configuration JSON, OpenCode stocke sa configuration dans :
C:\Users\MANOA PC\.config\opencode\opencode.jsonc
3
Ajouter le Provider dans l'interface

Dans la section Providers ou Models :

Champ Valeur à renseigner Remarque
Provider Type OpenAI Compatible Format standard universel
Provider Name Groq Cloud Nom d'affichage libre
Base URL https://api.groq.com/openai/v1 L'adresse du serveur d'inférence
API Key gsk_votre_cle_ici La clé générée à l'étape 1
Model ID openai/gpt-oss-120b Ou qwen/qwen3.8-27b
4
Tester l'exécution dans OpenCode

Ouvrez votre projet (par exemple votre dossier c:\wrk\Portf ou c:\wrk\prospectus-missi) dans OpenCode.

Ouvrez le panneau de discussion / d'édition et posez votre première question technique :

Prompt de test recommandé 
Analyse ce fichier JavaScript/HTML et propose 3 optimisations de performance et d'accessibilité sans altérer la logique existante.

✨ La réponse de GPT-OSS 120B ou Qwen 3.8 sur Groq doit apparaître en quelques secondes (débit typique : 250 à 400 tokens/seconde).

6. Configuration Prête à l'Emploi (Fichier opencode.jsonc)

Si vous préférez configurer directement le fichier JSON pour avoir tous les meilleurs providers gratuits en un seul clic, voici le bloc prêt à coller :

~/.config/opencode/opencode.jsonc 
{
  "providers": {
    // 1. GROQ : Vitesse pure & GPT-OSS 120B
    "groq": {
      "type": "openai",
      "name": "Groq (Ultra-Fast)",
      "baseUrl": "https://api.groq.com/openai/v1",
      "apiKey": "VOTRE_CLE_GROQ_ICI",
      "models": [
        { "id": "openai/gpt-oss-120b", "name": "GPT-OSS 120B" },
        { "id": "qwen/qwen3.8-27b", "name": "Qwen 3.8 27B" }
      ]
    },

    // 2. OPENROUTER : Spécialisé Code (Poolside Laguna & North Mini)
    "openrouter-free": {
      "type": "openai",
      "name": "OpenRouter (Free Pool)",
      "baseUrl": "https://openrouter.ai/api/v1",
      "apiKey": "VOTRE_CLE_OPENROUTER_ICI",
      "models": [
        { "id": "poolside/laguna-s-2.1:free", "name": "Laguna Code 2.1" },
        { "id": "cohere/north-mini-code:free", "name": "North Mini Code" },
        { "id": "nvidia/nemotron-3-ultra-550b-a55b:free", "name": "Nemotron-3 550B" }
      ]
    },

    // 3. GOOGLE AI STUDIO : Grand Contexte (1 Million de tokens)
    "google-gemini": {
      "type": "openai",
      "name": "Google Gemini",
      "baseUrl": "https://generativelanguage.googleapis.com/v1beta/openai/",
      "apiKey": "VOTRE_CLE_GEMINI_ICI",
      "models": [
        { "id": "gemini-3.8-flash", "name": "Gemini 3.8 Flash" },
        { "id": "gemini-2.5-pro", "name": "Gemini 2.5 Pro" }
      ]
    },

    // 4. OVHCLOUD : Anonyme & Sans clé (Secours gratuit)
    "ovh-anonymous": {
      "type": "openai",
      "name": "OVHcloud (No Key)",
      "baseUrl": "https://oai.endpoints.kepler.ai.cloud.ovh.net/v1",
      "apiKey": "none",
      "models": [
        { "id": "gpt-oss-120b", "name": "OVH GPT-OSS 120B" },
        { "id": "Qwen3.5-397B-A17B", "name": "OVH Qwen 397B" }
      ]
    }
  },
  "defaultModel": "openai/gpt-oss-120b"
}

7. Conseils & Stratégie selon vos Tâches de Développement

Au quotidien
Groq + GPT-OSS 120B

Idéal pour générer des fonctions, styliser du CSS, expliquer un bug ou écrire des tests unitaires en temps réel.

Gros Refactoring
Laguna ou North Mini

Modèles entraînés spécifiquement sur le code et les AST. Moins d'hallucinations de syntaxe lors de modifications structurelles.

Projet Complet
Gemini 3.8 Flash

Quand vous devez lui faire lire 15 fichiers en même temps grâce à sa fenêtre d'1 million de tokens.

🛡️
Règle d'or sur les Tiers Gratuits :
Les tiers gratuits peuvent utiliser les prompts pour l'entraînement (sauf opt-out explicite). Ne transmettez jamais de tokens de production, de clés d'API sensibles, ou de mots de passe de bases de données dans vos requêtes.
